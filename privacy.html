Privacy and data handling

This notice describes the current ResumeIQ implementation. Updated October 22, 2026. It is product information, not legal advice.

In brief: ResumeIQ extracts selectable text from a PDF and sends it with the target job description to Google Gemini for analysis. The original PDF is processed in the app session and is not stored in the ResumeIQ database by the current implementation.

What is processed

When you analyze a resume, ResumeIQ extracts selectable text from the PDF and sends that text together with the target job description to the Google Gemini API to generate analysis and recommendations.

Signed-in users

If you are signed in, ResumeIQ saves the extracted resume text, target job description, analysis, and any generated improved-resume draft in the Supabase history table. Saved jobs are stored there as well. Records are intended to be restricted to the authenticated owner through Supabase Row Level Security and application-side owner filters.

Guest users

Guest analyses are not saved to account history. Inputs and the generated report are held in the current Streamlit session. Refreshing, closing the session, or restarting the app can remove guest state.

Deletion

Signed-in users can delete individual history entries and saved jobs, or delete all saved ResumeIQ records from My Account. This does not delete the separate Supabase Auth account; the current interface does not provide a full account-deletion workflow.

AI limitations

ResumeIQ outputs are AI-generated estimates. They are not official results from an employer's applicant tracking system and do not guarantee interviews or employment. Review generated content, especially contact details, dates, education, skills, certifications, metrics, and achievements, before using it.

File limits and security

The app currently accepts text-based PDFs up to 10 MB and 40 pages. Scanned or image-only PDFs are not supported because OCR is not enabled. Keep passwords and API keys private; deployment secrets are configured in the hosting dashboard and are not part of this landing page.
