# ResumeIQ public landing page

This folder contains only the public, static marketing and privacy pages. It does not contain the Streamlit analyzer source, database credentials, or API keys.

The intended GitHub Pages address is `https://rapolusaihaneeshreddy.github.io/resumeiq-landing/`. Enable GitHub Pages from the `main` branch and `/ (root)` after publishing these files. The private Streamlit analyzer remains at its existing URL and is invite-only.

After publishing, add the landing page as a URL-prefix property in Google Search Console, verify ownership, submit `sitemap.xml`, and request indexing for the homepage. Search inclusion and ranking are not guaranteed or immediate.
